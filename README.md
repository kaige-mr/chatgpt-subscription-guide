## 三、 国内支付失败（Card Declined）原因剖析

1. 发卡行BIN码过滤：Stripe网关在底层屏蔽了所有发卡地为中国境内的信用卡。
2. 账单地址（AVS）核验：国内信用卡无法通过美区或欧区的地址库校验。
3. 代理IP欺诈评分：公共翻墙节点的机房IP在风控系统中信誉较低，容易直接触发高危拦截。
